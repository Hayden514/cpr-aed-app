# CPR and AED Emergency Response Web Application

CSCI 480 Capstone I project.

## Project Goal

Build a browser-based application that provides basic CPR guidance
and displays AED locations on an interactive map.

## Planned Core Features

- Display AED locations stored in a database.
- Show AED locations on Google Maps.
- Provide step-by-step CPR guidance.
- Support testing and documentation.
